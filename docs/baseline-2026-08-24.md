Local Dictation model directory under

config directory exists with settings/history/prompts/corrections, but no model

Available elsewhere on this Mac:

* S1-mini: `~/Library/Application Support/superwhisper/s1-mini.gguf` (462 MB).
* Cohere MLX checkpoint: `~/Library/Application Support/superwhisper/models/cohere-transcribe/cohere-transcribe-q4/model.safetensors` (1.5 GB), with tokenizer/config files alongside it.
* The current Rust Cohere backend expects the ONNX layout resolved by
  `app_paths::cohere_default_dir`; the installed MLX checkpoint is not that
  layout. The native Swift bridge is the path that can consume the installed
  Safetensors checkpoint.
* No Qwen GGUF or Parakeet model was present under this repository's model path.

No model was copied, downloaded, or loaded by this baseline.

## Safe benchmark commands

These do not launch the app and do not request microphone or Accessibility
permissions:

```sh
cargo test
cargo run --release --example preroll_lab
cargo run --release --example wake_word_lab
```

The two labs passed. `examples/latency_lab.rs`, `examples/prompt_lab.rs`, and
`examples/model_bakeoff.rs` are model-backed cleanup benchmarks and require
`--features cleaner` plus a GGUF at `GEMMA_MODEL_PATH` (the default repository
model is absent). `examples/streaming_lab.rs` and `examples/vad_stream_lab.rs`
require generated WAV corpora, Parakeet, and the cleaner; they were not run.

but currently fails before tests:

  extraneous `url:` label for the installed dependency API.

  unterminated Swift string literal.

## Documentation drift to resolve

* `Cargo.toml` package description still says “Parakeet TDT v3 + Qwen 2.5”,
  while the intended software-of-one stack is Cohere + S1-mini.
* `README.md` describes Cohere/Moonshine as sharing the CoreML path and gives
  CoreML-oriented latency claims. `src/transcriber.rs` and `CLAUDE.md:206–208`
  explicitly document that ONNX Runtime's CoreML EP cannot load Cohere's
  external-data sidecar, so Cohere falls back to CPU at roughly 5× realtime.
* `CLAUDE.md` still describes Qwen/Gemma as the cleanup default and uses
  historical “Gemma” names in benchmark comments; these should be made explicit
  if S1-mini becomes the sole cleanup model.
* `src/daemon.rs:178` says skipping cleanup saves roughly 860 ms, while
  `README.md:133` reports current cleanup at roughly 140–250 ms. One measured
  latency source should replace both stale comments.
* README/feature documentation still presents Parakeet, Moonshine, and Whisper
  as selectable alternatives even though the requested product scope is Cohere
  + S1-mini only.
