# Third-party notices

Local Dictation itself is dual-licensed MIT or Apache-2.0 (`LICENSE-MIT`,
`LICENSE-APACHE`). It builds on the work below. Nothing here is redistributed
with the source tree: model weights are downloaded or supplied by the user, and
the sound cues shipped in the binary are generated by
`scripts/audio/generate_cues.py`.

## Models

### S1-mini by Superwhisper

The cleanup model. **"S1-mini" by "Superwhisper"** — that exact name and
capitalization is required by its licence wherever the model is used.

- Model: <https://huggingface.co/superwhisper/s1-mini>
- GGUF builds: <https://huggingface.co/superwhisper/s1-mini-GGUF>
- Licence: Apache-2.0 with a naming clause. The Apache licence text is in
  `LICENSE-APACHE`; the model's own NOTICE file ships with the weights.
- Base model: Qwen3-0.6B by Alibaba Cloud (Apache-2.0),
  <https://huggingface.co/Qwen/Qwen3-0.6B>

Local Dictation loads the released weights unmodified. It supplies its own
prompts and guards; it does not fine-tune, quantize further, or otherwise change
the model.

### Cohere Transcribe (03-2026) by Cohere Labs

The speech-to-text model.

- Model: <https://huggingface.co/CohereLabs/cohere-transcribe-03-2026>
- Licence: Apache-2.0.

A 4-bit MLX conversion is used on device. `scripts/models/` re-keys Safetensors
header names for the public `mlx-audio-swift` module; tensor bytes are copied
unchanged. A converted checkpoint is a derived work of the Apache-2.0 model and
carries the same licence and attribution.

No copyleft licence is present. Regenerate the tally with:

```bash
cargo metadata --format-version 1 --all-features
```

The per-crate licence text is in each crate's source under
`~/.cargo/registry`. `cargo about` or `cargo deny` can produce a full text
bundle when one is needed for a release.

## Sounds

The state cues embedded in the binary (start, stop, success, cancel, latch,
error) are generated by `scripts/audio/generate_cues.py` from synthesized tones.
